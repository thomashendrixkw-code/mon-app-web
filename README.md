# creer moi une to do list

> Application web générée avec Base44 Clone

Projet généré automatiquement avec le studio **Base44 Clone** propulsé par l'IA Google Gemini.

## 🚀 Fonctionnalités
- Interface utilisateur moderne et réactive conçue avec React & Tailwind CSS.
- Iconographie intégrée avec `lucide-react`.
- Persistance locale des données via `localStorage`.
- Déploiement continu automatisé via GitHub Pages.

## 🛠️ Stack technique
- **Framework** : React 18
- **Styles** : Tailwind CSS
- **Icônes** : Lucide React
- **Bundler** : Vite

## 📦 Installation & Lancement local

```bash
# 1. Cloner le dépôt
git clone <url-du-repo>

# 2. Installer les dépendances
npm install

# 3. Démarrer le serveur de développement
npm run dev
```
